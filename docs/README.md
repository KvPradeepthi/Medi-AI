# Academic & Design Documentation

This directory contains system design assets and diagrams required for academic evaluation and final year submissions.

## Folder Directory Structure

```
docs/
├── Architecture/       # High-level architecture details and diagrams
├── ER Diagram/         # Entity Relationship models showing Mongoose schemas mapping
├── DFD/                # Data Flow Diagrams (Level 0, Level 1, Level 2)
├── Sequence Diagram/   # Sequence flows (e.g. Chat communication & Report uploads)
├── API/                # Static REST collections / postman outputs
├── PPT/                # Presentation slides for milestones
├── Screenshots/        # Final application user interface captures
└── Demo/               # Video demonstration details and walkthroughs
```

All design diagrams are prepared in standard vector format (Mermaid or PNG).
